# Architecture

Compass is structured around a simple, privacy-preserving flow:

1. Data is collected from user-managed sources
2. The application normalizes and stores the information
3. Insights and summaries are generated locally when possible
4. The system remains extensible for future automation and AI-assisted features

## Current Direction

- Desktop-first experience
- Local-first storage approach
- Google Sheets and Google Drive integration for practical data exchange
